# Big Building

React + TypeScript 的本地跑团 RPG。你只控制自己的角色；每次行动后，由 42-agent + DeepSeek 驱动在场 NPC 回应，规则引擎结算结果。

## 启动

需要 Node.js 22.13+ 和 pnpm 10.33.0。

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

打开 http://127.0.0.1:5173 。此命令同时启动网页（5173）和本地回合服务（5174）。修改服务端代码或模型配置后，需要重启这个命令。

将模型配置写入 `.env.local`，变量格式见 `.env.example`。`DEEPSEEK_API_KEY` 只由 Node 读取，不能使用 `VITE_` 前缀。默认模型为 `deepseek-flash`，请求发往 DeepSeek 官方 API。未配置凭据或模型失败时，NPC 按规则结束回合或进行敌对攻击，页面明确提示降级；不会将固定台词伪装成 AI 回应。

`pnpm run dev:web` 只启动界面，完整行动仍需要运行 `pnpm run agent:serve`。

## 游玩

- 左侧是艾琳自己的生命、能量、攻击、技能和对话，没有切换或控制其他角色的入口。
- 普通攻击使用当前手持武器；卸下武器后使用拳头。展开随身物品可装备武器或使用药草。
- 右侧点击地点方格移动，下面显示当地 NPC 与可交互物品。选择 NPC 后，左侧攻击和对话都面向这个对象。
- 输入框直接说话：Enter 发送，Shift + Enter 换行。NPC 会结合附近场景、自己的知识和最近对话回答。没有 NPC 时由旁白回应。
- 每次玩家行动后，在场 NPC 依次决定说话、攻击或结束。每个 NPC 最多说话一次、攻击一次，整轮最多 8 步；死亡立即结束。
- 回合处理中可以取消，取消会放弃整个尚未提交的回合。回合成功后自动保存；右上角「旅程」可以导入、导出、重放验证或重新开始。

可先去铁匠铺，和布兰交谈，拾取铁剑并装备；商店有一份药草可领取。前往书库调查秘典，随后选择如何面对王宫中的王权。庭院篝火可恢复生命与能量，但休整会推进一小时，正午王子的计划仍会发生。

「界隙之门」连接第二场景「灵境回廊」，穿越保留物品和等级，当前能量按 70% 转换。旧版三人存档导入后保留已有剧情和记录，并通过迁移指令绑定艾琳；不会在艾琳死亡后自动切换控制其他角色。

## 工程检查

```sh
pnpm run build       # TypeScript + 生产构建
pnpm test            # 规则、回合、模型传输、HTTP 和客户端提交边界
pnpm run agent:demo  # 旧行动建议协议的 CLI 示例，不修改浏览器旅程
pnpm run agent:live  # CLI 真实 DeepSeek 请求，需本地凭据，产生 API 用量
```

## 分层

```text
React：角色操作 / 地图方格 / 对话记录
  → POST /api/agent/turn（存档 + 玩家指令）
  → 重放存档 → 结算玩家动作 → 建立在场 NPC 队列
  → 42-agent + DeepSeek → npc_action → 规则校验 → 循环至结束
  → 返回玩家与 NPC 指令批次
  → 客户端再次校验并原子提交 → 自动保存
```

- `src/engine/`：纯规则、确定性重放、动作目录、NPC 回合协议。
- `src/game/`：唯一客户端提交入口、网络取消、存档与旅程隔离。
- `src/components/`：人物操作、场景方格、对话输入、旅程管理。
- `integrations/42-agent/turn.ts`：NPC 观察、受限工具和有界决策循环。
- `integrations/42-agent/server.ts`：仅监听 loopback 的 HTTP 桥接。
- `vendor/`：固定来源的 42-agent 运行时及许可证。
- [架构评估](docs/architecture.md)：职责边界、兼容方式和后续迁移条件。

## 当前边界

这是本地、单玩家原型。自然语言用于对话，数值和可执行动作仍由规则决定；模型不能凭台词新增物品、奖励或修改世界。NPC 使用最近 12 条本场景可用记录，不具备无限长期记忆；远处的正午刺杀、腐蚀和消息传播仍由确定性剧情规则驱动。

存档保留模型实际选择和台词，因此重放不再次请求模型。旧命令继续保持原有战斗语义，新旅程通过 `begin` 指令进入单人回合规则。当前未实现账号、多人同步、UGC、交易经济或线上权威资产服务。
