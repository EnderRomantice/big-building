# Big Building

React + TypeScript 的本地跑团 RPG。你只控制自己的角色；每次行动后，由 42-agent + DeepSeek 驱动在场 NPC 回应，规则引擎结算结果。

## 启动

需要 Node.js 22.13+ 和 pnpm 10.33.0。

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

打开 http://127.0.0.1:5173 。此命令同时启动网页（5173）和本地回合服务（5174）。修改服务端代码或模型配置后，需要重启这个命令。

将模型配置写入 `.env.local`，变量格式见 `.env.example`。`DEEPSEEK_API_KEY` 只由 Node 读取，不能使用 `VITE_` 前缀。默认模型为 `deepseek-flash`，请求发往 DeepSeek 官方 API。对话发送失败时会显示具体原因，保留输入，整轮不结算；网络、限流等临时故障最多重试一次。移动、攻击等非对话行动仍可在模型失败时按规则降级，并显示原因。

`pnpm run dev:web` 只启动界面，完整行动仍需要运行 `pnpm run agent:serve`。

## 游玩

- 顶栏包含 Home、用户首字头像与称呼。Home 可选择《九阙争衡》或旧篇《王座余烬》，新篇可选择沈砚、陆微、裴照，各自拥有独立开局与浏览器存档。旧篇继续使用艾琳。
- 普通攻击使用当前手持武器；卸下武器后使用拳头。展开随身物品可装备武器或使用药草。
- 右侧是统一内容区，默认显示场景与行动记录，通过「场景 / 地图」文字导航切换；地图按需展开。点击左侧角色姓名或场景中的 NPC，右侧显示人物属性、装备技能或最近对话。查看详情不推进时间。
- 地图只展示当前位置与相邻道路，保留不规则黑白颗粒与雾化表现。未到过的地方没有名字、人物或资源预告；点击道路或路径点查看线索、距离与耗时，抵达后揭名。先点击左侧攻击或技能，会自动返回场景选择对象，Esc 可取消。
- 友善人物也可以攻击：每次主动攻击降低 30 好感，同地点的相关见证者也会受影响。关系会随好感变化，NPC 根据实际伤害与关系作出回应。
- 左侧治疗术先选择自己或在场受伤人物，消耗 6 能量与 10 分钟，恢复最多 5 HP；不能治疗已死亡、满血或不在场的对象。
- 输入框可切换「行动」和「说话 / Say」，两种模式各自保留草稿。行动通过模型识别当前合法动作，显示成本与必要提示，确认后才执行；识别失败或不支持时不消耗回合，取消仍保留输入。Say 默认对整个当前场景说话：Enter 发送，Shift + Enter 换行；所有在场 NPC 都能听见。NPC 会结合附近场景、自己的知识和最近对话回答。没有 NPC 时由旁白回应。
- 每次玩家行动后，在场 NPC 各自运行一个 Agent 会话：观察 → 执行工具 → 读取结果 → 继续决策。工具支持说话、攻击、停战、自己移动和结束；停战真正解除敌对并恢复通行。每人最多 8 次模型回应、6 条动作记录；死亡立即结束。记录中的「决策与行动」可展开查看角色意图和实际工具。
- 发送失败不会消耗回合或触发规则反击，原文保留在输入框中，可直接重试。
- 回合处理中可以取消，取消会放弃整个尚未提交的回合。回合成功后自动保存；右上角「旅程」可以导入、导出、重放验证或重新开始。

## 九阙争衡

昭帝病危，承天主城与九座王爵城围绕继位之争各执立场。每座城含五个小镇，共 50 镇；每镇具备集市口、客栈、铁匠铺、杂货铺、医馆、书院、祠堂、巡检所、民居与郊野。加上城内设施和王宫，共有 570 个可到达地点、520 名人物与 50 只怪物。

十座城各有独立的利益、历史与地方争端；普通居民的背景和关系按城镇、职业模板生成，包含亲友、债务、庇护与敌对关系。这是可扩展的内容基础，并不意味着每名居民都有一条独立手写任务线。人物详情展示背景、等级、好感和已结识的关系对象。

玩家、NPC、怪物共用等级、经验、生命、气力、攻击、防御与成长模板；职业决定基础偏向。十个地区分别安排武器与传承技能，铁匠售卖武器、杂货铺售卖药草，书院传授当地技能。购买、装备、学习、施法、客栈休整和医馆疗伤均有真实规则与成本；未实现的奖励不能靠模型台词发放。

主线从寻访地方旧案开始：前往各王宫调查封存文书，亲自见过候选王爵，取得至少三地证词后，在第七日或之后回承天宫公开支持一位仍存活的王爵。途中第二、四、七日会推进争储消息。三名可选角色分别从军邮冤案、失踪星官、禁卫旧案进入故事。

旧篇仍保留铁匠、秘典、腐蚀与界隙剧情及历史重放规则。旧三人存档迁移后由艾琳继续；切换剧本不会抹去旧篇进度。

## 职业、技能树与跨世界角色

Home 的「创建角色」可输入名字，并从任意职业体系选职业，不受将要进入的剧本限制：

| 职业来源 | 可选职业 |
| --- | --- |
| 九阙争衡 | 游侠、方士、禁卫 |
| 王座余烬 | 游猎者、奥术师、誓约骑士 |
| 灵境回廊 | 界行者、魂咏者、灵契卫 |

每个职业有四个职业技能节点：Lv.1 基础、Lv.2 防护或治疗分支、Lv.4 爆发分支，以及需要两支前置的 Lv.6 终阶；另有该体系的三项通用技能。起始自带职业招式和 5 HP 治疗术，其余技能消耗技能点解锁。等级提供技能点，前置、等级、战斗状态、气力和冷却都由规则验证。点击左侧「职业与技能树」可以查看和研习，学会的技能会出现在操作区。

自建角色拥有跨世界身份：名字、职业、等级、经验、技能树全局保存；每个世界各自保留剧情、探索、装备、地区传承、生命和气力。旧世界存档回归时同步最新成长，不能把高等级角色覆盖回低等级；导入仍可重放。重开自建角色的世界仅重置该世界进度，保留跨世界成长。预设角色也会启用所在世界职业体系，但仍使用原有独立剧本存档。

NPC 和怪物也有职业、技能、气力、冷却和护盾。模型可使用 `npc_plan` 记录简短战术，使用 `npc_cast` 施法，或用 `npc_guard`、`npc_recover` 防守/回气。每轮普通攻击、施法、防守、回气四选一，不能连用多个主要行动；行动后模型读取实际结果再决定说话、撤离或结束。战术、冷却和气力跨轮保留。模型不可用时规则降级也会使用合法技能，并明确标注降级。

## 地图与旅行

不再显示全知世界地图。查看地图、人物资料、Home 和切换内容都在本地完成，不请求模型、不推进时间。只有确认行动才发送回合请求。

- 《九阙争衡》使用版本化的道路图：城中心连接五镇与其他城，镇街连接建筑，必须逐段走相邻道路；游戏时间随路程增加。
- 初始只认得所在街口；相邻未访地点仅给出声音、气味、足迹等线索，抵达后才写入足迹与揭示名字。各角色独立探索。
- 确认出发后保留局部地图，选中路径点和道路灰显并显示「移动中…」。收到完整回合后进入目的地；取消或失败恢复可选状态，不提前扣时间。
- 当前场景存在敌对人物时不能离开，须先解决遭遇。地图确认框展示通行限制，服务端仍重新验证移动与成本。
- 地图是局部道路示意，颗粒、雾化和不规则轮廓不代表可绕过道路自由移动。新剧本的地名与道路由内容版本固定，随机种子用于战斗；旧篇继续保留已保存的程序化地形与旅行规则。
- 时间为回合内结算，并非现实倒计时；世界消息随时间推进，NPC 只有在场回合，没有全世界后台在途模拟。

## 工程检查

```sh
pnpm run build       # TypeScript + 生产构建
pnpm test            # 规则、回合、模型传输、HTTP 和客户端提交边界
pnpm run agent:demo  # 旧行动建议协议的 CLI 示例，不修改浏览器旅程
pnpm run agent:live  # CLI 真实 DeepSeek 请求，需本地凭据，产生 API 用量
```

## 分层

```text
React：Home 与角色存档 / 局部探索 / 人物详情 / 对话记录
  → POST /api/agent/turn（存档 + 玩家指令）
  → 重放存档 → 结算玩家动作 → 建立在场 NPC 队列
  → 42-agent + DeepSeek → npc_* 工具 → 规则结算 → 工具结果回传同一会话 → 循环至结束
  → 返回玩家与 NPC 指令批次
  → 客户端再次校验并原子提交 → 自动保存
```

- `src/engine/`：纯规则、确定性重放、动作目录、NPC 回合协议。
- `src/game/`：唯一客户端提交入口、网络取消、存档与旅程隔离。
- `src/components/`：人物操作、场景方格、对话输入、旅程管理。
- `integrations/42-agent/turn.ts`：NPC 观察、受限工具和有界决策循环。
- `integrations/42-agent/server.ts`：仅监听 loopback 的 HTTP 桥接。
- `vendor/`：固定来源的 42-agent 运行时及许可证。
- [架构评估](docs/architecture.md)：职责边界、兼容方式和后续迁移条件。

## 当前边界

这是本地、单玩家原型。自然语言按输入模式用于对话或提出行动，数值和可执行动作仍由规则决定；模型不能凭台词新增物品、奖励或修改世界。NPC 使用最近至多 12 条本场景记录摘要（总计不超过 1200 字），不具备无限长期记忆；远处的争储消息与旧篇事件由确定性剧情规则驱动。

存档保留模型实际选择和台词，因此重放不再次请求模型。旧命令继续保持原有战斗语义；新篇通过 `campaign: succession-v1` 与初始角色选择重建世界。当前头像和称呼只保存在本地，未实现账号、多人同步、UGC 或线上权威资产服务。
